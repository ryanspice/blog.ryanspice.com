# Stack

## Technology stack

- TypeScript-first SvelteKit application with Svelte 5 runtime syntax.
- Frontend routing and rendering use SvelteKit 2.49.1 and `@sveltejs/kit`.
- Build orchestration uses Vite 7.2.6 with the SvelteKit Vite plugin.
- Content pipeline is Markdown-driven and rendered through `unified`/`remark`/`rehype` with custom processors in the app.
- Deployment target is vendored PHP Static adapter runtime for shared hosting.
- Production site uses static artifact flow plus `.htaccess` + PHP compatibility files generated by a custom adapter.
- Tests: Playwright + Vitest.

## Runtime and support tooling

- Node: >=20.11 (`package.json#engines.node`)
- Package manager used by repository scripts: `pnpm@9.0.3` (`package.json#packageManager`, `.github/workflows/deploy-blog.yml`)
- Microsoft auth runtime dependency: `@azure/msal-browser` + browser-side auth gate.
- Runtime env variables include `PUBLIC_BASE_PATH`, `PUBLIC_SITE_URL`, `VITE_MSAL_CLIENT_ID`, etc.
